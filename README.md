# GitHub Automation Dashboard

Standalone React + Vite dashboard with an Express API and PostgreSQL persistence.

## Requirements

- Node.js 20 or newer
- pnpm 9 or newer
- PostgreSQL 14 or newer

## Local setup

1. Install dependencies:

   ```bash
   pnpm install
   ```

2. Create the environment file:

   ```bash
   cp .env.example .env
   ```

3. Edit `.env` and set:

   - `DATABASE_URL` to your PostgreSQL connection string
   - `SESSION_SECRET` to a long random value

4. Create/update the database tables:

   ```bash
   pnpm run db:push
   ```

5. Start the React frontend and API together:

   ```bash
   pnpm run dev
   ```

6. Open the dashboard in your browser:

   ```text
   http://localhost:5173
   ```

7. Click **START AUTOMATION** in the existing dashboard. The API launches one Google Chrome automation window per active account and distributes 2-recipient batches across those accounts in round-robin order. All account windows run in parallel; a final odd recipient runs as a 1-recipient batch. Logs and aggregate progress stream into the dashboard. Pause/Resume uses local process controls on macOS/Linux; Stop terminates every runner and its Chrome window.

### Windows distribution

The Windows build is a per-user NSIS installer rather than a portable executable. Always download the installer to a local folder and install it; do not run it directly from a Google Drive-synced folder. The installer is code-signed when the GitHub Actions secrets `WINDOWS_CODE_SIGNING_CERTIFICATE` and `WINDOWS_CODE_SIGNING_PASSWORD` are configured. Without a trusted Windows code-signing certificate, SmartScreen or antivirus warnings cannot be removed reliably by application code alone.

Share the installer from the GitHub Release page whenever possible. If it must be shared through Google Drive, upload the exact installer generated by the release workflow and have users download it locally before opening it.

The Vite dev server proxies `/api` requests to `http://localhost:8080` during the normal `pnpm run dev` flow. The macOS one-click launcher uses port `8081` for the API so an older process on `8080` does not block startup.

### macOS one-click launcher

After completing the setup above, run this once:

```bash
chmod +x start-mac.command
```

After that, double-click `start-mac.command` in Finder. It starts the API and React frontend, then opens the existing dashboard. Keep the opened Terminal window running while using the automation. Clicking the dashboard's existing START button launches the separate visible Google Chrome automation windows.

## Useful commands

```bash
pnpm run typecheck
pnpm run build
pnpm --filter @workspace/api-spec run codegen
```

To run services separately:

```bash
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/github-automation-dashboard run dev
```

When running them separately, use `PORT=8080` for the API and `PORT=5173 API_URL=http://localhost:8080` for the frontend.

## Account format

Paste one account per line:

```text
email:password:2FA
```

Account passwords and 2FA values are encrypted before they are stored in PostgreSQL and are never returned to the browser.
